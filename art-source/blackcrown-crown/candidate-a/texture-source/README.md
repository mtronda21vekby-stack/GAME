# Candidate A procedural texture source

Candidate A texture sources are generated locally by Blender with a fixed seed.
No external images are used. The uncompressed PNG sources remain beside the
untracked `.blend` in `/tmp/blackcrown-production-crown-candidate-a/texture-source/`.

KTX2 is intentionally not claimed until a local Basis Universal toolchain is
available and the resulting runtime package has passed physical-device review.
