# EvoFish Shark Silhouette Lock

## Rule

All shark skins must use the same base silhouette.

Do not change:

- body length;
- head shape;
- tail shape;
- dorsal fin shape;
- side fin placement;
- mouth position;
- eye position;
- side-view facing-right pose;
- transparent isolated asset framing.

Allowed changes:

- color palette;
- stripes;
- glow accents;
- scars / markings;
- small decorative surface details;
- rarity-specific lighting.

Not allowed:

- changing anatomy;
- making the shark shorter, wider, or monster-like;
- changing pose or angle;
- adding armor that changes silhouette;
- adding weapons or large props;
- drawing a different species silhouette for a shark skin.

## Locked prompt

```text
Create a new shark skin variant for EvoFish Next using the exact same locked shark silhouette as the reference tiger shark.

Keep the silhouette unchanged: same side-view pose facing right, same long shark body, same head shape, same powerful tail, same tall dorsal fin, same pectoral fins, same mouth position, same eye position, same proportions and framing.

Only change the surface design: colors, stripes, markings, glow accents, texture, rarity details and small cosmetic highlights. Do not change anatomy, body length, fins, pose, perspective, shape language or scale.

Stylized 2D mobile game asset, premium quality, transparent background, isolated single shark, clean readable silhouette, high visual clarity, no text, no UI, no environment.
```
