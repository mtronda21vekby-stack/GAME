# BlackCrown Digital Crown Candidate A

This directory is a local visual-review candidate, not the approved production
Crown. Its manifest is fetched only by the allowlisted Nexus Lab override:

```text
VITE_BC_CROWN_ASSET_OVERRIDE=candidate-a
?nexuscrown=candidate-a
```

The canonical `/experience/crown/crown.manifest.json` remains disabled. Remove
the override to return immediately to the procedural Crown fallback.
