Деплой

  1. Заливаешь этот репозиторий в GitHub.
  2. Cloudflare → Pages → Create project → Connect to Git → выбираешь repo.
  3. Framework preset: None. Build command: пусто. Output: /.
  4. Pages → Custom domains: добавь blackcrown.work и (опционально) www.
